# QMT 行情数据分层与订阅生命周期

迁移任何依赖历史 K 线、盘中分钟线、成交量或停牌状态的策略时使用本参考。

## 官方数据模型

QMT 行情分为三类：

1. 本地数据：已下载到客户端的历史文件。`get_market_data_ex(subscribe=False)` 只读取本地数据。
2. 全推数据：全市场最新快照。`get_full_tick` 无需逐标的订阅、没有历史序列，适合最新价格、当日累计成交量和证券状态。
3. 订阅数据：指定品种的 tick、1分钟、5分钟或日线动态行情。订阅有权限上限，不同品种和周期分别计数；超限后可能前值填充或不再更新。

官方入口：

- 行情基础概念与函数对比：<https://dict.thinktrader.net/innerApi/question_answer.html#行情相关>
- 行情函数与订阅/反订阅：<https://dict.thinktrader.net/innerApi/data_function.html>
- 内置 Python 行情示例：<https://dict.thinktrader.net/innerApi/code_examples.html>

## 请求决策表

| 数据用途 | 接口 | `subscribe` | 前提 |
|---|---|---:|---|
| 截至前一交易日的历史日线/分钟线 | `get_market_data_ex` | `False` | 预先下载对应基础周期 |
| 全市场 ETF 历史成交额/价格 | `get_market_data_ex` 分批 | `False` | 禁止为全市场建立实时订阅 |
| 当日连续分钟 K 线 | `subscribe_quote` 后 `get_market_data_ex` | `True` | 只覆盖受控候选池并核对额度 |
| 最新价格、当日累计成交量、证券状态 | `get_full_tick` | 不适用 | 只有最新快照，无历史序列 |
| 回测当前 bar | `get_market_data_ex` | `False` | 使用本地回测数据 |

不要使用统一表达式 `subscribe=(RUN_MODE == "LIVE")` 包办所有请求。LIVE 只说明策略正在实盘运行，不说明某次请求需要实时订阅。

## 推荐生命周期

1. 盘前或候选池生成前，用 `subscribe=False` 读取已下载历史数据，完成流动性和历史指标筛选。
2. 候选池形成后，为确实需要连续分钟线的标的逐只调用 `C.subscribe_quote(code, period="1m", ...)`，保存返回订阅号。
3. 订阅建立后再读取当日分钟线；不要在交易判断中第一次订阅后立刻把返回的空表或填充数据当成真实最近 N 根 K 线。
4. 股票池变化时，对移除标的调用 `C.unsubscribe_quote(sub_id)`；策略 `stop(C)` 时释放全部显式订阅。
5. 日志记录请求标的数、有效订阅数、失败数、失败返回值或异常样本。不得假设券商客户端的具体额度。

`get_market_data_ex(subscribe=True)` 会自动订阅，但这种订阅没有可管理的订阅号，只能停止策略释放。动态池策略优先显式 `subscribe_quote`，不要依赖 `set_universe` 或反复自动订阅累积额度。

## 历史数据准备

- `subscribe=False` 不会从服务器自动补齐缺失历史数据。
- 在迁移报告中列出策略需要下载的品种范围、基础周期和时间区间。
- 每天盘后增量补充日线；若策略次日需要历史分钟窗口，同时补充相应1分钟或5分钟基础周期。
- 大范围历史查询按固定批次执行，批次大小是查询负载控制，不会改变订阅额度；不得通过拆批规避订阅上限。

## 临时停牌与数据不可用

临时停牌判断采用三态结果：

- `ACTIVE`：取得至少 N 根有效分钟线，且存在成交量大于零的分钟。
- `SUSPENDED`：取得至少 N 根当前交易日、时间不晚于当前 K 线的真实分钟线，成交量全部小于等于零。
- `DATA_UNAVAILABLE`：未订阅、订阅失败、空表、少于 N 根、时间戳无效、日期不匹配或字段缺失。

实现要求：

- 批量查询候选池，禁止排名循环中逐只重复请求。
- 使用 `fill_data=False`，避免缺失 K 线被合成为零成交量。
- 空数据和不足 N 根不得返回“停牌”。交易阶段遇到 `DATA_UNAVAILABLE` 时保守阻止交易，并明确记录为行情不可用。
- 同一 K 线缓存判断结果，避免重复查询和重复日志。
- 可先用 `get_full_tick` 的证券状态排除全天/当前明确停牌，再用真实分钟线判断“连续 N 分钟无成交”。

## 验收样本

至少验证：

1. 全市场历史日线请求均为 `subscribe=False`，运行前后显式订阅数不增加。
2. 候选池订阅成功数与目标数一致；失败时输出返回值或异常。
3. 活跃 ETF 最近 N 根分钟成交量包含正常非零值，结果为 `ACTIVE`。
4. 空表、少于 N 根、错误日期和订阅失败均为 `DATA_UNAVAILABLE`，不能显示“临时停牌”。
5. 构造 N 根真实零成交量分钟线时才得到 `SUSPENDED`。
6. 股票池变化和策略停止后，旧订阅号已执行反订阅。
